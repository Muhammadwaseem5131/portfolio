How I got here

About

Someone broke into the system at the NGO I work with — student records ended up exposed. I helped stop the damage. That is when security became serious for me.

I am 22 years old, from Chishtian, Pakistan. I taught myself cybersecurity by building a home lab in my bedroom — a pfSense firewall, a three-host Windows Active Directory domain, and a Kali Linux machine I use to attack my own network. I run penetration tests, collect the logs, and then try to detect my own attacks from the defender's side. That loop — attack, detect, fix — is how I learn.

The lab taught me that existing security tools give you too much raw data and not enough clear answers. So I started building my own: ScanMesh runs five scanners and merges their output into one report. LogMind reads security logs and tells you what happened in plain language. OmniAudit checks code for real vulnerabilities and filters out the false alarms. I use machine learning where it helps — but the core of everything I build is cybersecurity. That is what I want to study in Korea.

OmniAudit · 2026

Telling a developer which security warnings are real

An AI-assisted, local-first code security auditor. Python 3.10 and FastAPI behind a React 19 dashboard. Your code never leaves your machine unless you opt in.

Problem
AI-generated code ships with real bugs. Scanners catch them but return too many false alarms.
Method
Bandit scans the code and scores each finding. Gemini marks which ones are real and which are noise.
Result
The AI can label findings but never remove them. Code stays on your machine. Python only for now.

ScanMesh · 2026

Five scanners, one correlated report

A rule-based security-tool orchestrator. Chains nmap, ZAP, sqlmap and tshark into one automated pipeline — no AI, 100% deterministic.

Problem
A pentester runs each tool by hand, copies output between them, and manually writes up five separate dumps into one report.
Method
One target in, five tools chained by a rule engine. Findings on the same endpoint and vuln family merge — two tools agreeing = one high-confidence result.
Result
ZAP suspects SQL injection, sqlmap confirms it, ScanMesh merges them into one critical finding. Unit tests + CI on every push.

LogMind · 2026

Explaining security-log anomalies in plain language

Detects unusual patterns in security logs and explains them with a risk level, MITRE ATT&CK mapping, and recommended actions. Python stdlib only — no installs, no internet.

Problem
Security logs show something happened, but not what it means or what to do next.
Method
Ten pure-function detectors over an event list, plus a live-monitoring mode that tails logs continuously and alerts on anomalies.
Result
55/55 attack logs detected (recall 1.00), macro F1 0.89. 15 false alarms on hard-ambiguous benign logs — each documented with why.

Why Korea, and what happens after

Study plan

I am applying to the Department of Smart Security (스마트보안학과) at Konyang University. I taught myself the basics by building a home lab and writing my own tools, but there is a limit to what self-study can teach — I have never had a mentor review my work, or a classroom where I can learn from other students solving the same problems. Konyang's curriculum pairs theory with hands-on projects and industry experience, which is exactly the environment I need to grow from someone who builds small tools alone into someone who can secure real systems. As attacks grow smarter — malware that learns, phishing that adapts — defenders need structured training to keep up, and that is the direction I want to study in.

Pakistan's tech sector is growing fast — banks, telecom operators, and government systems are scaling up their digital infrastructure every year. That growth creates a real shortage of cybersecurity professionals who can do the hands-on work: building detections, running incident response, and securing production systems. After the degree I want to gain professional experience in Korea's security industry, then bring that expertise back to Pakistan — not as theory from a textbook, but as skills shaped by real operations. The shortage at home is not talent, it is trained practitioners.

  1. 2027

    Korean language year

    Konyang's Smart Security department teaches entirely in Korean and requires TOPIK 3 for admission after the language year. That is the target.

  2. 2028–2032

    B.Sc. — AI and security engineering

    Department of Smart Security (스마트보안학과), Konyang University. The work I want to reach is anomaly detection on network and host telemetry — models that hold up at a real base rate.

  3. 2032 onward

    Professional practice, then building capacity at home

    Hands-on experience in Korea's security industry — incident response, detection engineering, real operations. Then back to Pakistan to help close the professional shortage with skills from the field, not just from a textbook.
